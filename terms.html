// 02. Descrição do serviço

O Bot Redsec KD é uma ferramenta gratuita que oferece os seguintes serviços dentro do servidor BFBR:

• Consulta de KD: Busca e exibe estatísticas de Battlefield 6 via API pública gametools.network.
• Atribuição de cargos: Concede cargos no Discord com base no KD e rank competitivo do jogador.
• Salas de voz temporárias: Criação e gerenciamento automático de canais de voz.
• Atualização automática: Atualiza as estatísticas e cargos dos jogadores cadastrados diariamente.
// 03. Cadastro e uso

Para se cadastrar, o usuário deve informar voluntariamente sua gamertag EA e plataforma. O cadastro implica que o usuário:

• Possui direito legítimo de uso da gamertag informada.
• Autoriza o bot a consultar suas estatísticas públicas de jogo via API gametools.network.
• Autoriza o armazenamento do seu Discord ID, gamertag, plataforma e identificadores técnicos da conta EA (persona_id / nucleus_id) para fins de funcionamento do bot.
• Compreende que seus cargos no servidor serão atribuídos ou alterados automaticamente com base nas estatísticas obtidas.
