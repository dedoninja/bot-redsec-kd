Aviso: O Bot Redsec KD e a comunidade BFBR não possuem qualquer vínculo oficial com a EA, DICE ou a marca Battlefield. Este é um bot independente criado para auxiliar na gestão de uma comunidade de jogadores de Battlefield no Discord.
// 01. O que é este bot

O Bot Redsec KD é um bot do Discord criado para a comunidade Battlefield Brasil (BFBR). Suas funções principais são rastrear estatísticas de Battlefield 6 dos jogadores (KD, rank competitivo, etc.) por meio da API pública gametools.network, atribuir cargos no Discord com base no desempenho, gerenciar salas de voz temporárias e executar atualizações automáticas diárias das estatísticas dos jogadores cadastrados.

// 02. Dados coletados

Os dados abaixo são coletados no momento do cadastro e atualizados automaticamente a cada 24 horas:

Dado Origem Finalidade
Discord ID Discord Identificar o usuário no banco de dados
Gamertag EA Informado pelo usuário Buscar estatísticas na API gametools.network
Plataforma Informado pelo usuário Filtrar corretamente os dados na API (ea, steam, psn, xbox, epic)
Data de cadastro Gerado pelo bot Registro interno
persona_id / nucleus_id API gametools.network (pública) Identificadores técnicos da conta EA usados para consultas futuras à API

Estatísticas de jogo (KD, rank, Human%, etc.) são consultadas em tempo real na API pública gametools.network e não são armazenadas — apenas exibidas sob demanda.

// 03. Onde os dados são armazenados

Os dados são armazenados em um arquivo users.json em um servidor privado hospedado na plataforma Fly.io (região São Paulo, Brasil). Nenhum dado é compartilhado com terceiros, vendido ou utilizado para treinar modelos de inteligência artificial.

// 04. Retenção e exclusão
Remoção automática
Ao sair do servidor BFBR, seus dados são removidos automaticamente do banco de dados em até 24 horas.
Remoção manual
Enquanto você permanecer no servidor, pode solicitar a exclusão dos seus dados a qualquer momento entrando em contato com um membro da @Staff BFBR ou diretamente com o administrador do bot, @Dedo_Ninja, via Discord.
// 05. Permissões do Discord (Privileged Intents)

O bot utiliza as seguintes permissões privilegiadas do Discord:

Permissão Para que é usada
Server Members Intent Gerenciar salas de voz temporárias (detectar canais vazios para deletá-los automaticamente) e atribuir cargos aos membros
Message Content Intent Compatibilidade com comandos de prefixo legados (!comando) utilizados em versões anteriores do bot
Presence Intent Reservado para funcionalidades futuras relacionadas ao status de presença dos jogadores
// 06. LGPD (Lei Geral de Proteção de Dados)

Em conformidade com a Lei nº 13.709/2018 (LGPD), você tem os seguintes direitos sobre seus dados:

• Acesso: Solicitar quais dados seus estão armazenados.
• Correção: Solicitar correção de dados incorretos (ex: gamertag errada).
• Exclusão: Solicitar a remoção dos seus dados a qualquer momento.
• Portabilidade: Solicitar seus dados em formato legível.

Para exercer qualquer um desses direitos, entre em contato via Discord com @Dedo_Ninja ou com qualquer membro da @Staff BFBR no servidor Battlefield Brasil.

// 01. What is this bot

Bot Redsec KD is a Discord bot created for the Battlefield Brasil (BFBR) community. Its main functions are tracking players' Battlefield 6 statistics (K/D ratio, competitive rank, etc.) through the public gametools.network API, assigning Discord roles based on performance, managing temporary voice channels, and running daily automatic stat updates for registered players.

// 02. Data collected

The following data is collected at registration and automatically updated every 24 hours:

Data Source Purpose
Discord ID Discord Identify the user in the database
EA Gamertag Provided by user Fetch statistics from the gametools.network API
Platform Provided by user Correctly filter API results (ea, steam, psn, xbox, epic)
Registration date Generated by bot Internal record
persona_id / nucleus_id gametools.network API (public) Technical EA account identifiers used for future API queries

In-game statistics (K/D, rank, Human%, etc.) are fetched in real time from the public gametools.network API and are not stored — they are only displayed on demand.

// 03. Data storage

Data is stored in a users.json file on a private server hosted on Fly.io (São Paulo, Brazil region). No data is shared with third parties, sold, or used to train artificial intelligence models.

// 04. Retention and deletion
Automatic removal
When you leave the BFBR server, your data is automatically removed from the database within 24 hours.
Manual removal
While you remain in the server, you may request deletion of your data at any time by contacting a member of the @Staff BFBR or directly contacting the bot administrator, @Dedo_Ninja, via Discord.
// 05. Discord Privileged Intents

The bot uses the following Discord privileged intents:

Intent Purpose
Server Members Intent Manage temporary voice channels (detect empty channels for automatic deletion) and assign roles to members
Message Content Intent Backward compatibility with legacy prefix commands (!command) used in previous bot versions
Presence Intent Reserved for future features related to player presence status
// 06. Your rights

As a Brazilian-based service, this bot complies with Brazil's General Data Protection Law (LGPD, Law nº 13.709/2018). You have the following rights regarding your data:

• Access: Request what data is stored about you.
• Correction: Request correction of incorrect data (e.g., wrong gamertag).
• Deletion: Request removal of your data at any time.
• Portability: Request your data in a readable format.

To exercise any of these rights, contact @Dedo_Ninja or any member of @Staff BFBR on the Battlefield Brasil Discord server.
