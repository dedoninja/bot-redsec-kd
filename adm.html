Este é o painel de documentação exclusivo para a administração do Discord BFBR. Aqui você encontra a referência completa de todos os comandos do @BotRedsecKD, incluindo os comandos restritos à equipe de administração, o funcionamento do sistema de detecção de suspeitos (Human Check), e a tabela de roles gerenciadas pelo bot.

O bot gerencia automaticamente as roles de KD Redsec dos membros cadastrados, cria e deleta salas de voz temporárias, e aplica roles de suspeita de cheat com base no Human% retornado pela API do Battlefield. Comandos com a tag ADM só funcionam para quem tem permissão de administrador no servidor.

// Como funciona o sistema
// REGISTRO
Cadastro do usuário
O usuário se cadastra pelo botão no canal #registrar-kd-redsec⭕ ou via /kd. O bot consulta a API do BF6, extrai o KD Redsec e o Human%, salva no banco e atribui as roles.
// ATUALIZAÇÃO
Ciclo automático 04:00
Todo dia às 04:00 (BRT) o bot reconsulta a API para todos os cadastrados e atualiza as roles de KD e suspeita. Admins podem disparar o ciclo manualmente com /force_update.
// ANTICHEAT
Detecção por Human%
A API retorna um índice de comportamento humano. Percentuais abaixo de 70% recebem roles de suspeito automaticamente. Quanto menor, maior a probabilidade de uso de cheat.
// SALAS
Salas temporárias de voz
Membros entram em canais ➕ Criar... e o bot cria uma sala personalizada. Quando fica vazia, é deletada automaticamente. O criador pode kickar membros da própria sala.

// Human Check — sistema anticheat
Faixa Classificação
100% – 70% Jogador normal. Padrão da maioria dos jogadores.
70% – 50% Suspeito. Comum entre jogadores competitivos e profissionais de FPS. Recebe @Sus 50-70%.
50% – 30% Possível cheater. Forte indício de comportamento não-humano. Recebe @Sus 30-50%.
Abaixo de 30% Cheater. Padrão estatístico muito fora do normal. Recebe @Sus 0-30%.
0,00% Perfil privado ou sem dados suficientes. Não se enquadra como suspeito.
Atenção: Human% baixo pode indicar farm com bots no Portal/Breakthrough

Se um usuário apresentar Human% muito baixo (abaixo de 50%), isso não significa necessariamente que ele usa cheat em partidas normais. Jogadores que farmam XP com bots nos modos Portal ou Breakthrough acumulam estatísticas com padrão não-humano — muitos kills seguidos sem mortes, sem variação — o que derruba o índice mesmo que eles joguem os outros modos honestamente.

Nesses casos, é necessário verificar manualmente:

1. Use /search_player ou /stats para ver os dados do suspeito.
2. Acesse o link da API JSON presente no embed de stats e faça o download do arquivo JSON completo.
3. Cole o JSON em uma IA (como ChatGPT ou outra) e peça uma análise detalhada dos dados — modos jogados, número de partidas por modo, kills, mortes e padrões por sessão.
4. Se ficar claro que o Human% baixo é proveniente de farm com bots (muitas partidas de Portal/Breakthrough com KD altíssimo e pouquíssimas mortes), e o comportamento em partidas normais parece legítimo, atribua manualmente a role @🐂 Fazendeiro ao usuário.

A role @🐂 Fazendeiro não remove as roles de suspeito automaticamente — ela serve como marcação interna para que a administração saiba que aquele perfil já foi investigado e a porcentagem baixa tem explicação legítima.
Aviso: Os valores são calculados com base no histórico total do jogador (Multiplayer, Redsec, Portal e demais modos). O uso recente de cheats pode ser temporariamente amortizado por horas de jogo legítimo anterior.
